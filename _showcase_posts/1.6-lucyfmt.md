A minimal formatter for [Odin](https://odin-lang.org/). It only fixes indentation and leaves everything else as you wrote it.

[Source on GitHub](https://github.com/lucypero/lucyfmt)

## What it does

- Indents with one tab per scope level (except `when` blocks).
- Adds one indent level to parameters split across multiple lines.
- Never adds newlines.
- Has no configuration, so every file it formats comes out the same.
